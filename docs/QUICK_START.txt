CodexBar Windows 便携版

1. 将 ZIP 全部解压，打开 CodexBar 文件夹。
2. 双击 CodexBar.exe。无需安装 Python 或 Conda。
3. 单击任务栏组件打开 Token 用量账本；双击打开设置；右键打开菜单。
4. 保留完整文件夹，包括 _internal，不要单独移动 EXE。
5. 如果源码版或旧版已在运行，先通过它的右键菜单退出，再双击新 EXE。
   程序采用单实例保护，已有实例运行时重复启动会静默退出。

账号额度与 token 明细

账号额度来自服务端；token 明细来自所选设备可读取的 Codex 日志。
日志用量不按当前登录账号归属，不能当作该账号所有设备的总量。
个人 Plus/Pro 的其他设备及云端 token 明细未接入，未读取的部分不会显示为零。
可在账本点击“官方账号用量”，通过浏览器查看官方账号页面。
任务栏或托盘图标右键菜单的“用量来源”可选择“本机”或已发现的 SSH 主机；选择保存在本机配置中。任务栏今日 token 和花费跟随该来源，远程 token 数前会显示“远程”。账本自己的来源选择独立，不会改变任务栏。
来源菜单和托盘提示会显示当前来源及状态。首次读取远程来源失败时显示不可用；连接中断但已有缓存时保留旧数据并标记不完整。
SSH 来源只覆盖所选主机，不代表同一账号的全部设备。额度仍来自所选 OAuth 账号，不会与设备用量合并。

统计包括数据库收录的会话，以及 sessions / archived_sessions 下的日志。
支持 CODEX_HOME、新版 state_*.sqlite、相对路径和归档移动后的日志。
缓存输入包含在输入中，推理包含在输出中；总 token 不重复加上这两部分。
~ 表示发现读取不完整；金额是 API 等价估算，不是实际订阅扣费。
服务端额度暂时失败时，任务栏用量仍独立读取当前选择的来源。

系统要求

Windows 10/11 x64。账本使用 Microsoft Edge WebView2 Runtime。
如果 WebView2 缺失，可从 Microsoft 官方页面安装：
https://developer.microsoft.com/microsoft-edge/webview2/
本包未签名，Windows 可能显示发布者未知。

第三方许可证位于 licenses 文件夹，隐私与安全说明随包附带。
